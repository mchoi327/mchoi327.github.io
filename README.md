# Mingeun Choi

Source for [my academic website](https://mchoi327.github.io/), with research, publications, teaching, and news.

Built with HTML, CSS, and JavaScript. Published through GitHub Pages from the `main` branch.

## Files

- `index.html`, `research.html`, `publications.html`, `teaching.html`: main pages.
- `news.html`: news archive; the latest three entries also appear on Home.
- `header.html`, `style.css`, `site.js`: shared navigation, styles, and interactions.
- `files/`: CV and download manifest.
- `images/`: profile and news photos. News images use `news_YYYYMMDD_event.ext`, matching the date of the news item.

## Local preview

Serve this folder through a local HTTP server. Opening the HTML files directly will not load the shared navigation or news feed. No build step is required.
